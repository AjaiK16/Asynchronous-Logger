# Asynchronous Multi-Threaded Logger

## 📝 Description

This project implements a **multi-threaded logging system** that offloads logging operations to a dedicated thread, improving performance in real-time systems.

## 🚀 Features

- ✅ Asynchronous logging using **dual buffers**
- ✅ **Non-blocking** log writing for efficiency
- ✅ **Thread-safe** with `std::mutex`
- ✅ **Timestamped log messages**
- ✅ **Makefile-based** for easy compilation

## 🛠️ Installation & Usage

```sh
git clone https://github.com/yourusername/async-logger.git
cd async-logger
make
./logger
cat log_output.txt
# Asynchronous-Logger
```
